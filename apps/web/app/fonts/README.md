# Bundled fonts

Downloaded on 2026-09-12 from the Google Fonts CSS2 API (Latin subset, variable WOFF2). These files are served by Next.js locally so builds and visitors do not depend on Google font requests. Existing font families and weight ranges are preserved. Chinese characters continue to use the system fallback stack.

Original font projects and their SIL Open Font License 1.1 notices:

- space-grotesk (500–700): https://github.com/google/fonts/tree/main/ofl/spacegrotesk; see `space-grotesk-OFL.txt`.
- ibm-plex-sans (400–600): https://github.com/google/fonts/tree/main/ofl/ibmplexsans; see `ibm-plex-sans-OFL.txt`.
- jetbrains-mono (400–600): https://github.com/google/fonts/tree/main/ofl/jetbrainsmono; see `jetbrains-mono-OFL.txt`.
- stix-two-text (400–700, normal and italic): https://github.com/google/fonts/tree/main/ofl/stixtwotext; see `stix-two-text-OFL.txt`.
