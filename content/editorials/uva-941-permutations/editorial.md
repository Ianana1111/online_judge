## 題意與限制

给定長度一到二十的小寫字串 S，輸出按字典序排列後的第 N+1 個不同字串，N 從零起算。本站既有案例包含重複字元，因此明定使用不同的多重集合排列；排列總數是 |S|! 除以各字元次數階乘的乘積，並保證 N 小於實際總數。原文的 |S|! 僅適用於全部字元不同。

## 解題思路

字典序可依第一個字元切成連續區塊：先是所有以 a 開頭的不同排列，再是 b，以此類推。只要能用多重集合公式算出每個候選前綴的區塊大小，就能用排名跳過整塊，而不必生成、排序前面的所有字串。

逐個決定答案位置。所有以 a 開頭的合法排列形成第一個區塊，接著是 b 開頭，以此類推。假設選字元 c，先把它的剩餘次數減一；若剩 R 個字元、各字元頻率 f_i，該區塊大小為 R!/∏f_i!。

若 N 小於該區塊大小，答案就在這裡，確定選 c，繼續處理剩下位置。否則整個區塊都在目標之前，將 N 減掉區塊大小，恢復 c 次數，再試下一個字元。頻率為零的字元不考慮。最大 20! 約 2.43×10^18，仍可用有號六十四位元整數精確保存，不能用浮點階乘或三十二位元排名。

## 範例推演

S=aabb 的不同排列依序是 aabb、abab、abba、baab、baba、bbaa。N=2 時先看 a 開頭區塊，剩 abb，有 3!/2!=3 種，N<3，因此選 a。下一個位置先看 a 開頭區塊，剩 bb，只有一種，跳過後 N=1；改選 b，剩 ab，有兩種，N<2，繼續定位便得到 abba。

## 正確性

對固定前綴，按下一個字元遞增分組後，各區塊本身連續且依字典序排列。固定某字元後，餘下不同排列由多項式係數精確計數，重複字元不會產生重複字串。若 rank 超出當前區塊，扣除其大小正好轉成後面區塊的相對排名；若落在當前區塊，保留剩餘排名就是該字元前綴內的定位問題。歸納每一位置都保留正確前綴與相對排名，字元耗盡時得到唯一目標字串。

## 複雜度

字母種類固定二十六，每個位置最多測二十六個候選，每次用二十六個頻率算區塊大小，總時間 O(|S|·26²)，空間 O(|S|+26)。階乘只預算零到二十。階乘分母採逐個整除，任一中間分母乘積都對應合法的部分多重集合計數，結果仍為整數，不會因中間截斷失真。

## 常見錯誤

- 按字符位置計算 |S|!，將相同字元的交換當成不同结果。
- 以 N 除 (R−1)! 的普通 factoradic 直接處理重複字元。
- 把零起算排名當成一起算，所有結果偏移一格。
- 跳過一個字元後沒有恢復其頻率。
- 用 double 或 int 儲存 20! 與排名。
