## 題意與限制

MSLCM(N) 是所有最小公倍數等於 N 的整數集合中，元素總和的最大值，集合不能重複放同一數字。要求從二到 N 的 MSLCM 總和。N 大於一且最多兩千萬，至多二百行查詢，零終止。這題不是求最小因數和，也不是只取質因數或質數冪。

## 解題思路

若集合的 LCM 是 N，每個元素都必須是 N 的正因數。將所有正因數全部加入，因為它們都是正數，總和只會增加；集合又包含 N 本身，LCM 仍恰為 N。因此 MSLCM(N) 就是正因數和 sigma(N)。

交換兩層求和，從一到 N 的因數和總和等於 sum[d×floor(N/d)]：因數 d 會出現在 d、2d、3d 等 floor(N/d) 個數裡。題目從二開始，所以最後扣掉 sigma(1)=1。利用 floor(N/d) 分段相同，若目前 left 的商是 q，相同商可一路延伸到 right=floor(N/q)，整段貢獻 q×(left+right)×(right−left+1)/2。

## 範例推演

N=4 時，各數的最大集合分別是 {1,2}、{1,3}、{1,2,4}，總和為 3+4+7=14。交換求和後先算 1×4+2×2+3×1+4×1=15，再扣掉一得到十四。N=10 時商在 d=6 到 10 都是一，可以整段一次計算，不必逐個列出這五個數。

## 正確性

合法集合只能包含 N 的因數，而全部因數集合本身合法且所有元素為正，故它唯一達到最大可能總和。有限雙重求和可交換次序，每個 d 對總和的出現次數正好是其倍數個數 floor(N/d)，所以新公式與原問題相等。對 q=floor(N/left)，整數除法保持 q 的最大下標恰是 floor(N/q)，因此分段不漏項、不重疊，等差級數公式精確求出這段所有 d 的和。所有分段相加再去掉一的因數和，便得到所求二到 N 的總和。

## 複雜度

整數商只有 O(sqrt N) 種：小下標至多 sqrt N 個，大下標的商至多 sqrt N 種。因此每次查詢 O(sqrt N) 時間、O(1) 額外空間，不必存兩千萬格陣列。中間乘法與答案用 64 位元整數，題目上界內可安全容納。

## 常見錯誤

- 只加 N 或質因數，漏掉其他正因數。
- 集合允許重複元素，將原本有限最大值誤解成無限。
- 交換求和後只算 floor(N/d)，忘記每次要加因數 d 本身。
- 忘記最後扣除 sigma(1)，答案多一。
- 使用 32 位元累加，最大範圍溢位。
