排序用的內容與最後顯示的內容要分開。每行 original 完整保留，包含逗號旁的空白；另外把各欄位切出來，去掉欄位首尾 ASCII 空格，得到排序用的 key。

比較兩行時，不是把整行當字串比，而是逐欄位比較。第一個不同欄位的字典序決定順序；前面欄位全部相同、其中一行先結束時，欄位較少的排前面。數字字樣也是字典序，不要擅自轉成整數或自然排序。例如 10 排在 2 前面。

空欄位仍是一個欄位，分割不能把相鄰逗號或最後的逗號忽略。C 手動切逗號，在複製的 buffer 上放終止字元；Python split(',') 與 Java split(",",−1) 都保留空欄位。修剪 key 不能改到 original，否則輸出會丟失原空白。

排序鍵相同的行也都要保留，不能用 set 去重。C 以原始索引當最後的比較條件，Python／Java 的穩定排序保留原順序；題目也接受其他同鍵順序。每组之间空一行。

M 行、最多 L 欄位、每欄最多 D 字元，排序最壞 O(M log M·LD)，空間 O(MLD) 保存原行與鍵。
