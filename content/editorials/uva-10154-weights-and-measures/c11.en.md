C has no built-in priority queue, so the program implements an array-based max-heap: `push` appends the value and swaps it upward, and `pop` removes the top, moves the last element to the root and swaps it downward. Both are O(log n).

Turtles are stored in a `Turtle` struct and sorted with `qsort` using `by_strength`: strength first, then weight. The comparator uses `(a > b) - (a < b)` so no subtraction can overflow. Reading uses `while (n < 6000 && scanf(...) == 2)`, which stops at end of file and can never write past the array.

The main loop adds each turtle, updates `total`, and whenever the total exceeds that turtle's strength it subtracts and removes the largest weight at the top of the heap. The final heap `size` is the answer.
