給定 M 列、N 欄的字元網格，每次查詢指定一個格子 `(r,c)`，求以該格為中心，且所有格子字元都相同的最大正方形邊長。正方形必須完整位於網格內，邊與網格的列、欄平行。

列、欄索引皆從 0 開始，左上角是 `(0,0)`，右下角是 `(M−1,N−1)`。中心位於一個格子，因此答案為奇數，最小為 1。

### Input

第一行是測試組數 T，`1 <= T < 21`。每組第一行是 M、N、Q：M 和 N 分別是列數、欄數，`1 <= M,N <= 100`，Q 為查詢數且小於 21。

接著有 M 行，每行包含 N 個字元，表示網格。最後有 Q 行，每行包含查詢座標 r、c，滿足 `0 <= r < M`、`0 <= c < N`。

### Output

每組輸出 Q+1 行。第一行以單一空格分隔輸出 M、N、Q。接下來依查詢順序，每行輸出對應的最大正方形邊長。

例如範例網格的 `(1,2)` 為中心，其周圍 3×3 區域都是 `b`，答案是 3。

題意依 [UVa 10908 官方題面](https://onlinejudge.org/external/109/10908.pdf) 整理。
