一條射線切掉整條直線上的樹。只要直線經過至少兩個不同位置，就能用這兩點枚舉；重複座標的樹也要一起算進去。用叉積判斷共線，不用浮點斜率，垂直線也自然正確。

一般可以在「已切掉哪些樹」的遮罩上做 DP。這個版本再利用一個簡化：任意兩棵樹都能用一條直線切掉，所以還需切 need 棵時，ceil(need/2) 是保證可行的上界。真正可能改善它的，是一次新增至少三棵的射線。

因此 search(removed) 先以 ceil(need/2) 當答案，再枚舉能額外切掉三棵以上的直線。若一條線在目前狀態只新增一或兩棵，可以把它留到最後由兩兩配對處理，不會更差；射線的切除順序可交換，所以這樣不會漏掉最佳解。要看的是「新增」的樹數，不是該線原本的總樹數。

need=target−已切數，小於等於零時就完成。題目只要至少 target 棵，不應強迫第一棵樹一定被切。用記憶化避免不同射線順序重算同一遮罩，重複的直線遮罩也先去重。預計算 bits 表計算樹數，支援正式 Python 環境。

n≤16，遮罩最多 2^n 個，候選線 O(n²)，枚舉共線 O(n³)，保守搜尋界 O(2^n n²)，空間 O(2^n+n²)。沒有三棵共線時直接得到 ceil(target/2)，不用遍歷所有遮罩。
