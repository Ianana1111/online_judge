## 題意與限制

零表示樹已被砍掉、一表示還有樹。從 M×N 矩陣選出全部為零、邊與格線平行的最大矩形，輸出格數面積。M、N 都是一至一百，兩個零結束。要求矩形而非正方形，也不能把不相鄰空地拼成一塊。

## 解題思路

枚舉矩形上邊界 top，再逐步往下增加 bottom。用 clear[column] 記錄這一欄從 top 到 bottom 是否全部為零，新加一列時以 AND 更新。

上下界固定後，能形成矩形的欄位必須連續且 clear 全為真，因此只需掃描最長連續真值區段。遇到真就增加 current，遇到樹則歸零；以 current×高度更新面積。每換上邊界，所有欄重新設為可用。

## 範例推演

兩列分別為 0 0 1 0 與 0 0 0 0。若上下界涵蓋兩列，可用欄是前兩欄與最後一欄，最長連續長度二，面積四；不能把最後一欄一起算成寬三。若矩陣全零，答案就是 M×N；全一則零。

## 正確性

固定 top 後，clear 初始為真，每增加一列就與本列是否為零做 AND，故精確表示整段垂直區間無樹。固定上下界的任何合法矩形都對應一段連續可用欄，掃描枚舉每段的最大長度，找到該高度最佳面積。外層覆蓋全部可能上下界，因此全域最大值不會遺漏。

## 複雜度

共有 O(M²) 組上下界，每組掃 N 欄，時間 O(M²N)，最大約一百萬級更新。儲存矩陣 O(MN)，另有 O(N) 的欄狀態。不需枚舉四條邊的 O(M²N²) 方法。

## 常見錯誤

- 把一當成可用地，而題目要求全零。
- 欄狀態使用 OR，只要一格零就誤認整欄可用。
- 遇阻擋欄不重設 current，拼起不連續土地。
- 每下降一列就清空狀態，遺失之前列中的樹。
- 只找最大正方形。
