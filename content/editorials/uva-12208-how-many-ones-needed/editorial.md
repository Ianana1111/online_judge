## 題意與限制

給定 0≤a≤b≤2000000000，把閉區間內每個整數寫成二進位，求其中所有一的總個數。前導零不影響答案。最多一萬一千筆查詢，以 0 0 結束，終止那行不是查詢。區間可非常大，不能逐整數計算位元數；答案也可能遠超過三十二位整數。

## 解題思路

逐一列出區間中的數字顯然承受不了二十億的範圍，所以要把問題轉成可以整段計算的形式。先用前綴相減處理任意區間，再觀察每一個二進位欄位各自如何變化：最低位每一個數翻轉，下一位每兩個數翻轉，更高位也都呈現固定長度的零區與一區。不同位元可以獨立計數，最後相加，這正是把巨大區間壓縮成約三十一輪運算的來源。

定義 prefix(n) 為零至 n 之間所有整數的一總數，n<0 時定義為零。答案就是 prefix(b)−prefix(a−1)，同時涵蓋 a=0。

對某一個位元值 p=1、2、4、⋯，該位元在遞增整數中呈現 p 個零、p 個一的週期。零至 n 共 n+1 個數，完整週期各貢獻 p 個一；剩下 r=(n+1) mod (2p) 個數，只有超過前 p 個零的部分是一，所以額外貢獻 max(0,r−p)。把每個有效位元的貢獻相加，就得到整個前綴計數。

## 範例推演

區間五到十的各數為 101、110、111、1000、1001、1010，一的數量依次為二、二、三、一、二、二，總共十二。若計算零到七，三個位元各自在八個數中出現四次，總共十二，也符合完整週期公式。

## 正確性

固定某個位元，二進位進位規則使其精確重複 p 個零後 p 個一；從零開始計數，完整週期與剩餘前綴的貢獻因而由公式精確求得。每個一屬於唯一整數與唯一位元，把各位元的計數相加不会重複或遺漏。再以零至 b 的集合移除零至 a−1，剩下正好是所求閉區間；a=0 時移除空集合，而零本身沒有一，所以負前綴回傳零也正確。

## 複雜度

每個前綴至多處理三十一個位元，單筆時間 O(log b)、額外空間 O(1)。最多一萬一千笔也只需少量運算。所有週期、乘積及總和使用六十四位整數。

## 常見錯誤

- 使用 n 而非 n+1 表示前綴數量，漏算終點。
- 扣 prefix(a) 而非 prefix(a−1)，把 a 也移除。
- 用三十二位計數器保存超過十億範圍的位元總數。
- 把 0 0 當成正式案例輸出，導致編號多一筆。
- 在剩餘段不足 p 時仍加上負數。
