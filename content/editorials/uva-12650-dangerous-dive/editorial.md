## 題意與限制

有 N 位編號一到 N 的潛水員，其中 R 位回來並交回名牌。輸入給出回來者的編號，請依遞增順序輸出沒有回來的人；如果全部回來，輸出一個星號。限制 1≤R≤N≤10000，至少一位回來，多組資料讀到 EOF。每個缺少編號後要有一個空白。

## 解題思路

建立大小 N+1 的布林陣列 present，全設為 false。讀到回來者 id 時將 present[id] 設為 true。接著從一到 N 掃描所有編號，false 的就是沒有交回名牌者，直接輸出即可自然遞增。

輸入順序不一定排序，不能只觀察相鄰輸入是否跳號。也不能只計算缺少幾人，因為題目要實際編號。用 missing 記錄是否曾輸出任何缺少者，若最後仍為 false，才印 *。

## 範例推演

N=5、回來名牌是 3、1、5，標記後一、三、五存在，因此輸出 `2 4 `。若 N=3，名牌依序 3、1、2，雖然順序不同，全部編號都有出現，答案仍是 *。N=1、R=1 也是這個全員返回邊界。

## 正確性

讀取完成後，present[id] 為 true 的充要條件是該編號出現在返回名單，因為只有讀到該名牌才會把那一格設真。完整掃描一至 N 因此恰好選出所有未返回編號，不漏也不多。掃描方向遞增保證輸出排序；若完全沒有 false，就等價於全員返回而印星號。

## 複雜度

讀名牌 O(R)，掃描 O(N)，總時間 O(N+R)，布林標記空間 O(N)。不需要排序，並且能直接處理亂序返回名單。

## 常見錯誤

- 依返回名單原順序推測缺號，沒有處理亂序。
- 掃描到 id<N，漏掉最後一位。
- 陣列只開 N 格，編號 N 越界。
- 全員回來時輸出空行而不是 *。
- 每組未清除標記，上一組的返回者影響下一組。
