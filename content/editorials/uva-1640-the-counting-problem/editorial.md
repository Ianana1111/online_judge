## 題意與限制

把 a 與 b 之間所有正整數寫成一般十進位表示，統計零到九各出現多少次，兩端都算。a、b 皆大於零且小於一億，不保證 a≤b；至多五百組，0 0 結束。數字不補前導零，所以一到九並不含零，十才首次貢獻一個零。

## 解題思路

先做前綴函式 count(n)，計算一至 n 的各數字次數，區間答案便是 count(max(a,b))−count(min(a,b)−1)。對個位、十位、百位逐一計算。某位權 factor，把 n 分成 higher、當前 digit、lower。

對非零 d，完整的高位循環貢獻 higher×factor；當前 digit>d 再補 factor，digit=d 補 lower+1，digit<d 不補。零必須另外排除高位全部為零時的假前導位：只有 higher>0 才計，先加 (higher−1)×factor，再依 digit 是否為零補 lower+1 或 factor。各位的次數相加即總次數。

## 範例推演

一到十有十個一位數字位置與十的十位：零一次，一兩次，二至九各一次。若直接把零套成一般數字，會把 01、02 等不存在的表示算進去。a>b 時先交換，例如十到一仍與一到十相同；a=b 時則只計這一個數所有位數，重複數字也要逐位累加。

## 正確性

固定一個位權時，低位每跑 factor 個值，當前數字增加一；每十個數字形成完整循環，因此所有完整高位循環的非零 d 都恰出現 factor 次。剩餘尾段依當前 digit 與 d 的大小關係，精確產生零個、lower+1 個或 factor 個。對 d=0，第一個高位循環代表缺少此位的短數字，不能計入，所以扣掉一個 factor；higher=0 時整段都沒有真正的此位零。這給出每一位的正確計數，位與位代表不同出現位置，求和不會重複同一位置。最後前綴相減精確保留閉區間內的數字。

## 複雜度

每個前綴只處理 O(log n) 個十進位位置，每個位置固定十種數字，因此每組 O(log max(a,b)) 時間，額外 O(1) 空間。使用 64 位元整數保存位權、乘法與累計值，不需要真的枚舉最多近一億個數字。

## 常見錯誤

- 零與一到九套同一公式，計入前導零。
- 閉區間相減用 count(a) 而非 count(a−1)，漏掉左端。
- 假設 a 一定小於 b，輸出負數。
- digit 等於目標時只加 lower，漏掉當前數 n。
- 將 0 0 哨兵當成要統計一個零的案例。
