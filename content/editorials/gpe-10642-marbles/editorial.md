## 題意與限制

N 顆彈珠彼此可區分，K 個盒子也有編號，每盒至少放 X 顆，計算分配方法數，對 1000000007 取模。N≤100000、K≤50、1≤X≤N，最多五十組。這不是同名的整數方程 Marbles，也不是把不可區分物品用隔板分配；交換任兩顆不同彈珠所在的盒子，可能形成不同方法。

## 解題思路

這題的彈珠彼此不同，所以只決定每盒幾顆還不夠，還得決定是哪幾顆。與其一次列舉所有盒子大小，不如盯住最後一顆彈珠：移除它後，原盒是否還合格？剛好 X 顆和超過 X 顆會產生兩種不同的小問題，這個分類既能涵蓋全部情況，也能自然帶出組合數。

令 f(n,k) 是把 n 顆不同彈珠放入 k 個有標號盒子、每盒至少 X 顆的方法數。觀察編號最後一顆彈珠所在的盒子。若該盒超過 X 顆，移除最後一顆後仍全部合格，共有 k·f(n−1,k) 種；若該盒恰有 X 顆，先選盒子 k 種，再從其他 n−1 顆選 X−1 顆陪它，剩下分到其他 k−1 盒，共有 k·C(n−1,X−1)·f(n−X,k−1) 種。

因此 f(n,k)=k[f(n−1,k)+C(n−1,X−1)f(n−X,k−1)]。初始化 f(0,0)=1，其他零盒情況為零。按盒子數遞增、同一列按彈珠數遞增，使用前後兩列；只算 kX≤n，且保留給未處理盒子至少 X 顆。預算階乘及反階乘，組合數可 O(1) 查得。X=1 時另用滿射容斥 Σ(−1)^j C(K,j)(K−j)^N，在這個常見最大規模分支免建 DP。

全部輸入先讀完，把相同 K、X 的一般案例分組，只對該組最大的 N 計算一次；最後一列已包含所有較小 N 的答案，可以共用，仍按原案例順序輸出。

## 範例推演

N=4、K=2、X=2。最後一顆所在盒只能恰有兩顆，因此選盒子二種、選同盒彈珠三種，剩下兩顆只能進另一盒，答案六。N=10、K=5、X=3 時，最低需求十五顆，立即得到零。N=1、K=1、X=1 時唯一彈珠放進唯一盒子，答案一。

## 正確性

任一合法分配中，最後一顆所在盒的大小不是恰好 X，就是大於 X，兩類互斥且完整。大於 X 類移除最後一顆會唯一對應一個合法 n−1 顆分配以及原盒編號；反向把最後一顆放回該盒即可恢復。恰好 X 類則唯一決定原盒、X−1 顆同伴及其他盒子的合法分配，反向同樣唯一。相加即得到遞迴，且所有引用不是較少盒子，就是同列較少彈珠，因此迭代順序正確。只保留 n≤N−(K−k)X 不會漏掉最終答案的依賴：下一列引用的 n−X 必在上一列上限內。X=1 的容斥直接排除至少一個空盒，與同一定義等價。

## 複雜度

一次預處理 O(100000+log MOD) 時間、O(100000) 空間。一般每個不同 (K,X) 群組 O(Nmax·K) 時間、O(Nmax) 額外空間；X=1 時每個案例改為 O(K log N)，另用 O(T) 保存查詢及答案。每個乘積至多兩個模值或 K 乘兩個模值的和，long long 足夠。程式不列舉 K^N 種實際分配，也不建立十萬乘五十的完整 DP 表。

## 常見錯誤

- 把彈珠當成不可區分，用隔板法計數。
- 忘記盒子有標號，少乘選盒子的 K。
- 將至少 X 誤當成恰好 X。
- 恰好 X 分支選 C(n,X)，把已指定的最後一顆又重選一次。
- 只用一列卻覆寫尚未讀取的前一盒子數狀態。
