Input punctuation is consumed into characters and an adjacency matrix deduplicates edges. `n<=1` directly prints n and continues reading EOF cases.

Minimum degree initializes a valid bound for noncomplete graphs. Each endpoint pair builds a fresh residual network, with unit internal capacities and n for endpoint and original-edge arcs. Dinic stops after sending the current bound because that pair then cannot improve it. Fresh construction prevents residual capacities from leaking between pairs.
