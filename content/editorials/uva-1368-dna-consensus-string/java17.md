Hamming distance 是逐位置相加，而且某欄選什麼不會限制其他欄，所以全域最佳可以拆成 n 個獨立決策。某欄選出現次數最多的字母，能讓不相同的列數最少；若最多次數並列，只要從字典序小到大掃並保留第一個，就同時得到整串最小字典序。

Hamming distance 是每個位置不相同的次數，所以總成本可以按欄拆開。某欄若選字母 c，只有原本不是 c 的 m−count[c] 條需要算錯；要最小化成本，就選該欄出現最多的字母。

同票時依 A、C、G、T 的字典順序選最小者。實作以這個順序掃描，只有嚴格更多時才更新 best，因此相同次數會保留先遇到、字典序較小的字母。所有欄位各自最優後串起來即可。

每一欄獨立選出出現最多的鹼基；同票依 A、C、G、T 字典序，其他字元數就是該欄錯誤數。
