一般做法是記錄出現過哪些數字，但這題有個值得利用的特性：相鄰數字只能差 1。因此只要走過 0 與 base−1，中間的每一個數字必定都已走過。反過來，要出現所有數字也一定要碰到這兩個端點。

所以這個版本只用兩個旗標：第 0 位表示看過 0，第 1 位表示看過 base−1。dp[mask][last] 是目前長度、以 last 結尾、端點旗標為 mask 的數量。開頭不能為 0，先對 1..base−1 各放入一種單位長度的數字。

每一步只能接 last−1 或 last+1，先檢查範圍，再更新新數字帶來的旗標。使用獨立 next 表，避免同一輪新增的數字再被拿來延長。mask=3 才表示所有數字都看過。

題目要求最多 length 位，不是恰好 length 位，所以每一輪完整答案都要累加到 answer[length]。length=0 的答案自然為 0。所有計數對 1000000007 取餘數，C／Java 每次只加兩個已取餘數的數，32 位元仍安全。每種進位的預計算需 O(100×base×4) 時間，滾動 DP 空間 O(base)，另存 101 個長度答案。
