A proper divisor divides N but is not N itself. Test each integer from one through N−1 and add it when `N % divisor == 0`. N is at most 1000, so this direct definition-based loop is fast enough and easier to verify than factorization. Compare the completed sum with N: smaller means `deficient`, equal means `perfect`, and larger means `abundant`. For example, eight has proper divisors 1, 2, and 4, whose sum is seven. Read the case count first and print exactly one classification per case.
