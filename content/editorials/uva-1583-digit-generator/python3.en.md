A generator N of target M cannot exceed M because its digit sum is nonnegative. All targets are at most 100000, so enumerate candidate N values from small to large and compute `target=N+digitSum(N)`. Record N only when the target’s table entry is still zero. The first candidate reaching a target is the smallest generator, and later larger candidates must not overwrite it. An untouched zero means no generator, matching the required output. Each input query is then answered by one table lookup instead of a new search.

The python3 program updates the state using this invariant and handles every input branch explicitly.
