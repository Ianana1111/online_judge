在線段上，首個尚未覆蓋的孔一定可以當下一張補片的起點：若補片從更早處開始，將它右移到該孔不會漏掉仍需處理的孔，反而可能多蓋右側。因此每個狀態只需嘗試兩種長度。圓周唯一多出的困難是切點；把孔複製成兩圈並枚舉哪個孔先處理，就能讓每種跨零配置在某次枚舉中成為普通線段配置。

先把孔排序，再把每個位置加 C 複製一次，將圓周展成兩圈的線。依次假設每個孔是這次覆蓋的第一孔，只需處理從 start 起連續 N 個孔。對首個尚未覆蓋的孔 i，選一種補片從 hole[i] 開始，便能覆蓋到 hole[i]+T，包括端點；接著跳到第一個超過此界線的孔。

預先用雙指標算出兩種長度在每個 i 的下一孔位置。固定起點後，由後往前算 dp[i]=min(T1+dp[next1],T2+dp[next2])，超過此次 N 孔區段就截到終點，終點成本為零。最後在全部起點中取最小值，跨零的最佳貼法也包含在某個展開区段內。

將排序後的孔位置複製一圈，枚舉哪個孔作為線段起點。對每種補片長度預先用雙指標找出可覆蓋到哪個孔，再逆序 DP，取所有切點的最小成本。
