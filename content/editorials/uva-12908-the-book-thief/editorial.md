## 題意與限制

把一本書一到 N 的頁碼相加，但漏掉恰好一個正頁碼，最後得到 s。給定 1≤s≤10⁸，求漏掉哪一頁與書的總頁數。s=0 結束。漏頁不能是零，也不能超過 N，所以三角形數等於 s 時不能直接取該 N。

## 解題思路

完整頁碼和 T(N)=N(N+1)/2，漏掉的頁碼是 T(N)−s。因為它必須介於一到 N，等價於 T(N−1)≤s<T(N)。所以 N 正是第一個三角形數嚴格大於 s 的索引。

T(N) 單調增加，可以二分搜尋。high=20000 時三角形數已超過 10⁸，確保包含答案。找到 N 後直接算差，全部使用整數，避免平方根浮點誤差。

## 範例推演

s=9000 時 T(133)=8911、T(134)=9045，所以書有 134 頁，漏頁為 45。s=6 是 T(3)，不能回答漏零頁；下一個三角形數 T(4)=10，因此是漏第四頁、全書四頁。

## 正確性

合法漏頁 x 滿足 1≤x≤N 且 s=T(N)−x，整理得 T(N−1)≤s<T(N)。相鄰三角形數形成的這些區間互不重疊且覆蓋所有非負整數，因此唯一 N 是首個 T(N)>s 的索引。二分維持答案在 [low,high]，收斂後以差求 x，必定落在合法範圍。

## 複雜度

每次 O(log 20000) 時間、O(1) 空間。即使目前乘積在 int 邊界附近仍可表示，使用 long long 讓公式乘法與中間結果一致保持安全。

## 常見錯誤

- 找 T(N)≥s，三角形數輸入會得到漏零頁。
- 只把平方根公式向下取整，沒有修正端點。
- 把完整頁碼和當成已知 s，不補回漏頁。
- 顛倒輸出順序：應先漏頁再總頁數。
