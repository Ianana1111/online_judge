一千個數不能四層枚舉，但等式有個方便的拆法：把 c 移到右邊，左右就各剩兩個數。先算好所有 a+b，查詢時只問「有沒有等於 d−c 的配對」。不過題目要求四個元素不同，所以表裡不能只有和，還要留下索引，才能檢查這個看似吻合的配對有沒有偷用 c 或 d。

改寫為 a+b=d−c。預算所有不同索引的無序兩數和，保留兩個索引並按和排序。把原集合排序，從最大 d 往下嘗試，對每個 c≠d 用二分搜尋找和為 d−c 的配對，確認它的兩個索引也都不等於 c、d。

不能只保存某個和的一對索引，因為那一對可能與 c 或 d 重疊，另一對卻有效。相同和的配對可以掃描：由於集合值互異，同一個數最多出現在該和的一對裡，所以被 c、d 排除的配對至多兩組，第三組若存在就一定可用。

先把每對數的和與兩個索引一起排序。由大到小試 d，對每個 c 二分找和為 d−c 的配對，並確認四個索引互不重複；用整數壓縮索引可避免大量物件耗掉記憶體。
