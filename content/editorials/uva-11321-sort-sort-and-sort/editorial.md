## 題意與限制

每組給 N 個有號 32 位元整數，以及正整數 M；N、M 最多 10000。排序的第一順位是「除以 M 的餘數」，由小到大。餘數相同時，奇數排在偶數之前；都是奇數時由大到小，都是偶數時由小到大。

負數取餘數遵循 C 語言規則，例如 `-100 % 3 = -1`，不能改成非負餘數。輸入以 `0 0` 結束，這題特別要求最後的 `0 0` 也必須輸出。

## 解題思路

將題目的排序優先順序直接寫成比較函式。比較兩數 a、b 時，先比餘數；若不同，較小者在前。再比較奇偶性；若不同，奇數在前。最後才依共同的奇偶性決定數值方向。

判斷奇數應使用 `value % 2 != 0`，不能用 `== 1`，因為負奇數在 C++ 中除以 2 的餘數是 −1。

若兩數相同，最後的嚴格比較自然回傳 false，符合 `sort` 所需的嚴格排序關係。不要用 `<=` 或 `>=`，否則相等元素會同時被判斷成應排在彼此前面。

## 範例推演

以 M=3 且數字為 3、6、9、12、15 為例，它們餘數都是 0。先排列奇數，按遞減順序得到 15、9、3，再排列偶數，按遞增順序得到 6、12。

再看 −5 與 −4：餘數分別是 −2、−1，所以 −5 在 −4 前面。負數也先比餘數，再套奇偶與大小規則，不能直接沿用一般整數升序，也不能把負餘數正規化成 0 到 M−1。

## 正確性

可以把每個數視為帶有三層排序鍵：第一層是 C 語言餘數；第二層是奇數優先的分類；第三層在奇數組使用數值降序，在偶數組使用數值升序。比較函式逐層比較，只有前面的鍵相同才進入下一層。

因此任意兩個不同排序位置的元素，其先後順序都與題目規則相符。這種分層排序具有一致的傳遞性，相同元素彼此不小於對方；`sort` 依此關係排序後，整個序列符合所有順位要求。

## 複雜度

比較函式只做固定次數取餘數與比較，單次 O(1)。排序 N 個整數需 O(N log N) 時間，儲存數列需 O(N) 空間；標準排序另使用 O(log N) 左右的呼叫堆疊。

## 常見錯誤

- 使用 Python 式非負餘數解讀負數，與題目規定不同。
- 用 `a % 2 == 1` 判斷奇數，漏掉負奇數。
- 所有奇偶組都升序，忘記奇數需要降序。
- 用非嚴格比較處理相同值，破壞排序函式要求。
- 讀到 `0 0` 立即結束，忘了這題要求也輸出終止行。
