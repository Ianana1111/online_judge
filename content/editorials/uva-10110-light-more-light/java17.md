不必模擬前 n 盞或前 n 趟；我們只關心第 n 盞，而它被切換的趟數正是 n 的因數個數。把因數依乘積 n 配對後，問題立刻化成判斷是否存在無法和另一個不同因數配對的平方根。

第 n 盞只在 i 整除 n 時被切換，所以切換次數等於 n 的正因數個數。因數通常可以配成 d 與 n/d 兩個；只有 n 為完全平方數時，平方根會和自己配成一組，造成一個沒有相異夥伴的因數。於是完全平方數有奇數個因數，最後亮著，其餘都有偶數個，最後關閉。

接著只需要精確判平方。用整數二分搜尋 1 至 65535，因為 65536²=2³² 已經超出合法 n。每次比較 mid² 與 n，平方太小就搜尋右半、太大就搜尋左半；相等便找到答案。計算使用 64 位無號整數，避開 32 位有號乘法溢位與浮點開根號邊界。

平方與輸入以 `long` 儲存；若中點平方小於目標，就提高搜尋下界。
