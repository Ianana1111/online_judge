## 題意與限制

走廊有 n 盞一開始關閉的燈，第 i 趟只切換編號為 i 倍數的燈。走完 n 趟後，問最後一盞燈是否亮著。1≤n≤2³²−1，零表示輸入結束，不處理零。答案使用小寫 yes 或 no。若真的逐趟走訪，最大輸入會需要數十億次操作，因此必須找出最後一盞被切換的規律。

## 解題思路

不必模擬前 n 盞或前 n 趟；我們只關心第 n 盞，而它被切換的趟數正是 n 的因數個數。把因數依乘積 n 配對後，問題立刻化成判斷是否存在無法和另一個不同因數配對的平方根。

第 n 盞只在 i 整除 n 時被切換，所以切換次數等於 n 的正因數個數。因數通常可以配成 d 與 n/d 兩個；只有 n 為完全平方數時，平方根會和自己配成一組，造成一個沒有相異夥伴的因數。於是完全平方數有奇數個因數，最後亮著，其餘都有偶數個，最後關閉。

接著只需要精確判平方。用整數二分搜尋 1 至 65535，因為 65536²=2³² 已經超出合法 n。每次比較 mid² 與 n，平方太小就搜尋右半、太大就搜尋左半；相等便找到答案。計算使用 64 位無號整數，避開 32 位有號乘法溢位與浮點開根號邊界。

## 範例推演

n=12 的因數配對是 (1,12)、(2,6)、(3,4)，共六次切換，最後關閉。n=16 則有 (1,16)、(2,8)、(4,4)，不同因數共五個，最後亮著。n=1 也有唯一因數 1，必須輸出 yes；65535²=4294836225 是合法範圍內最大的平方數，仍然應接受。

## 正確性

每趟操作的條件等價於趟數是 n 的因數，因此燈亮的充要條件是因數數量為奇數。映射 d↦n/d 將非平方根因數兩兩配對，只有完全平方數才有唯一固定點，故奇數因數恰好對應完全平方數。二分搜尋每次保留仍可能平方等於 n 的整數區間，找到相等或區間耗盡時，就分別證明是或不是平方數。

## 複雜度

二分搜尋固定上界 65535，最多約十六次比較；以一般 n 表示為 O(log n) 時間、O(1) 空間。mid² 最大為 4294836225，在 unsigned long long 的範圍內。

## 常見錯誤

- 以為奇數 n 的燈才亮，混淆數值奇偶與因數個數奇偶。
- 使用 int 計算大於 46340 的平方，造成有號溢位。
- 平方根上界只設 46340，漏掉合法的大平方。
- 二分搜尋用 low<high，最後剩一個候選時未檢查。
- 把零當作平方數輸出，忘记它是終止符。
