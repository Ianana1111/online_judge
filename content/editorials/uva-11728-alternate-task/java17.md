因數和至少包含 n 本身，所以查詢 S≤1000 時，任何候選 n 都不會超過 1000。這讓我們可以反向預處理整個值域：先用篩法同時計算每個 n 的完整因數和，再建立「因數和 → 最大原數」的查表，所有查詢便成為 O(1)。

因為 n 自己就是因數，所以因數和至少為 n；若 S≤1000，候選 n 絕不會超過 1000。先用類似篩法的方式：對每個 divisor，把它加到所有倍數的 sum 裡。這樣每個 sum[n] 都是 n 的完整因數和。

接著讓 n 從小到大走，若 sum[n]≤1000，就寫入 largest[sum[n]]=n。相同因數和出現多次時，後面較大的 n 會覆蓋前面的，最後自然保留最大解。沒有被寫過的位置維持 −1。

`Arrays.fill` 明確設定沒有答案的狀態；同一和的較大 `n` 會覆蓋較小值。
