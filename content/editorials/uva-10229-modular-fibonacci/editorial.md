## 題意與限制

Fibonacci 數列定義為 F₀=0、F₁=1、Fₙ=Fₙ₋₁+Fₙ₋₂。對每一組 n、m，輸出 Fₙ 除以 2ᵐ 的非負餘數。0≤n≤2147483647、0≤m<20，讀到 EOF，沒有零終止符。尤其 `0 0` 是正常案例，答案為零，後面仍可有其他資料。

## 解題思路

看到 n 可以到二十多億，就能先排除逐項遞推。接著可以問：「如果已經知道第 k 項附近的資訊，能不能一次跳到第 2k 項？」Fibonacci 的倍增恆等式正好做到這件事，而且每次都把索引減半。為了讓奇數索引也容易接續，我們不只求 Fₙ，而是固定回傳相鄰的 `(Fₙ,Fₙ₊₁)`。

直接走到第 n 項太慢，也不能先儲存巨大的完整 Fibonacci 數。改用快速倍增：已知 a=Fₖ、b=Fₖ₊₁，就能計算 F₂ₖ=a(2b−a)、F₂ₖ₊₁=a²+b²。遞迴先求 n/2 的連續兩項，再按 n 的奇偶組合成所需的一對。

所有加法與乘法都可在模數下進行，因為同餘關係保留這些運算。計算 2b−a 時先加 mod 再取餘數，避免 C++ 負餘數。m=0 的模數為一，所以所有結果都必須是零，連基底 F₁ 也用 1%mod。

## 範例推演

n=10、m=3 時，模數是八；F₁₀=55，因此答案是七。若遞迴先得到 F₅=5、F₆=8，倍增公式給出 F₁₀=5×(16−5)=55。實作在模八下得到 a=5、b=0，正規化後 c=5×3 mod8=7，與完整計算相同。n=0 時直接回傳零。

## 正確性

基底回傳 (F₀,F₁) 的正確餘數。假設 n/2=k 的遞迴結果正確，Fibonacci 加法公式可推出 F₂ₖ=Fₖ(Fₖ₋₁+Fₖ₊₁)=a(2b−a)，以及 F₂ₖ₊₁=a²+b²。n 偶數時回傳這兩項；n 奇數時回傳後一項及兩者和，恰為 (F₂ₖ₊₁,F₂ₖ₊₂)。數學歸納證明每層都正確；模運算不改變最終餘數。

## 複雜度

每層把 n 減半，時間 O(log(n+1))，遞迴堆疊 O(log(n+1))。mod≤2¹⁹，兩個平方的和小於 2³⁹，因此 long long 足以保存乘法中間值，不依賴有號溢位碰巧保留低位元。

## 常見錯誤

- 用 F₁=0 的另一套索引，整個答案偏移一項。
- 將模數誤寫成 2m 或 2ᵐ⁻¹。
- n 很大仍用線性迴圈。
- 乘法先用 int 溢位再取模，行為不具可攜性。
- 2b−a 為負時直接取餘數。
- 把 `0 0` 當結束，或在 m=0 時回傳未取模的一。
