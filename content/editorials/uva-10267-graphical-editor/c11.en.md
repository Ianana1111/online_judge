Store the picture as rows of characters. Read one command per line so an unknown command discards its whole line. `I` creates a picture, `C` recolors it without changing size, and point, line, and rectangle commands visit their inclusive cells. Coordinates are column-first and one-based, so subtract one for array access.

For fill `F`, remember the starting color. Return immediately if it already equals the target. Otherwise run four-neighbor BFS through pixels of the old color, recoloring each when enqueued to prevent duplicates. The image has at most 10,000 pixels, fitting the fixed integer queue.
