## 題意與限制

圖像寬高皆五至五十，點號為背景、星號為骰子表面、X 為點數像素。所有非背景像素的四方向最大連通區是一顆骰子，而每個 X 的四方向最大連通區是一個點。斜角接觸不算相連。保證至少一顆骰子，每顆一至六點，求每顆點數並遞增排序輸出。

## 解題思路

同一張圖有兩種不同的「物件」：骰子由所有非背景像素連成，而點數只由 X 像素連成。先用較寬鬆的連通條件圈出一整顆骰子，再在其內用較嚴格條件數 X 連通塊，就能避免把一個大點數按像素計數，也不會讓星號切斷骰子。

分成兩種連通區處理。第一層 BFS 只要不是背景就可走，找出一顆完整骰子的所有座標，使用 dieSeen 避免重複找同顆。再遍歷這些座標，每遇到尚未處理的 X，就把點數加一，並用第二層 BFS 將同一片 X 全部標記到 pipSeen。

兩種標記不可混用：骰子 BFS 需要穿過表面星號與點數 X，點數 BFS 卻只能走 X。保留原圖不改字元，讓兩種語意清楚分離。完成一顆便保存點數，最後整份排序，同點數的不同骰子仍各輸出一次。

## 範例推演

一大片相連 X 即使有二十五個像素，仍只是一個點，也可能單獨構成一顆骰子。兩個 X 若中間隔著星號，屬於同一顆骰子但不同點。兩顆骰子只在角落碰到，四方向沒有連接，必須分開計；同一骰子兩個點也不能因斜角碰到就合成一點。

## 正確性

第一層 BFS 從未訪問非背景格開始，恰收集所有四方向可達的非背景格，即一個最大骰子連通區。每格只在第一次進入時標記，因此所有骰子完整且互不重複。固定一顆骰子，第二層每次從未訪問 X 出發，恰遍歷一個最大 X 連通區，所以每個點正好加一。同片 X 不可能跨越不同骰子，因為 X 連通也必然是非背景連通，因此全圖共用 pipSeen 安全。

## 複雜度

每個像素在骰子 BFS 至多一次，X 像素在點數 BFS 再至多一次，時間 O(WH)，加上 D 顆骰子的排序 O(D log D)。原圖、兩張訪問表與佇列共 O(WH) 空間。使用迭代 BFS 避免最大連通圖的深遞迴。

## 常見錯誤

- 直接數 X 字元，將一個多像素點算成多點。
- 使用八方向連通，錯把斜角相接合併。
- 骰子連通只走星號，讓 X 造成假斷裂。
- 共用同一張訪問表，第二層無法辨認尚未計數的點。
- 用集合保存結果，錯刪相同點數的不同骰子。
