Classify a tiling by its left edge. A vertical brick fills the first column and leaves width N−1. If the top brick is horizontal, a second horizontal brick must fill the bottom; together they use two columns and leave width N−2. These disjoint cases give `ways[N] = ways[N−1] + ways[N−2]`. The empty wall has one completed tiling and width one has one tiling. Precompute through 50, then answer each query until the zero sentinel. The 50th count exceeds 32 bits, so C and Java need 64-bit integers.

The java17 program implements this reasoning directly and follows the exact input terminator and output format.
