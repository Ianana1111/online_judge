`readLines(n)` invokes `getline` exactly n times, retaining empty strings and genuine trailing spaces. A trailing CR from Windows line endings is removed. After formatted line counts, `ignore` consumes the rest of the numeric line before text reading.

Vector equality checks all lines exactly. `visible` receives `unsigned char` before `isspace` and appends every nonwhitespace character. The standard character count sums stored line sizes. Run numbering increments once and the final line follows the CPE-specific verdict-and-count format.
