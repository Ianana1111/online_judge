## 題意與限制

每兩行是一組資料：第一行給代入值 x，第二行由最高次項到常數項列出多項式係數。請計算導數在 x 的值，讀取到 EOF 結束。輸入數值與最終輸出絕對值都小於 2³¹，但題目沒有保證中間運算也在同樣範圍。

若有 n+1 個係數，多項式次數就是 n。原本 a[i] 對應的次數為 n−i，微分後係數變成 `a[i] * (n-i)`，次數減一；最後的常數項微分為 0，不應納入導數。

## 解題思路

可以先在紙上把多項式微分，再觀察真正要算的是「另一個多項式在 x 的值」。若逐項計算 x 的冪次，會做許多重複乘法；把導數改寫成巢狀形式後，Horner 法只需一次由高次到低次的掃描。這也讓常數多項式自然得到零，不必另外列很多次數特判。

先用微分公式取得導數係數，再以 Horner 法求值。例如三次式的導數為 `3a*x² + 2b*x + c`，可重寫成 `(3a*x + 2b)*x + c`。因此不必逐項計算 x 的高次方。

令 value 初始為 0。依最高次到最低次，對每個非常數項執行 `value = value*x + coefficient*power`，其中 power 是原本項的次數。處理到一次項後，value 就是導數值。

此參考解使用 Python 3 的整數精確運算，避免因中間值大於最終答案而溢位。係數行必須整行讀取，才能知道同一個多項式有多少項，不能把下一組的 x 一起當成係數。

## 範例推演

x=2、係數為 `1 1 1` 時，原式為 x²+x+1，導數為 2x+1。Horner 先得到 `0*2+1*2=2`，再得到 `2*2+1*1=5`，常數 1 不參與，答案為 5。

x=7、係數為 `1 -1` 時，原式 x−1 的導數恆為 1，因此只做 `0*7+1*1=1`。若係數只有一個數，原式是常數，迴圈沒有任何項需要處理，答案自然為 0。

## 正確性

導數係數依序記為 b0、b1、…、b(n−1)。處理前 k 個係數後，Horner 變數表示 `b0*x^(k-1)+b1*x^(k-2)+…+b(k-1)`。初始處理一項時顯然成立；再乘 x 並加上下一個係數，便得到前 k+1 項的相同形式。

由歸納法，處理所有導數係數後，value 就等於整個導數多項式在 x 的值。係數的微分權重由 n−i 正確計算，常數項被排除，因此結果正確。

## 複雜度

有 n+1 個係數時，需要 O(n) 次整數乘加，並儲存 O(n) 個係數。Python 整數的實際位元運算成本取決於中間數值大小，不能將任意長整數乘法視為固定成本；本題不必額外建立各項冪次。

## 常見錯誤

- 直接計算原多項式，忘記乘上各項原本的次數。
- 把係數由低次到高次解讀，或把常數項也累加進導數。
- 用浮點 pow 再轉回整數，導致精度誤差。
- 只因最終答案小於 2³¹，就假設所有中間乘積都可用 32 位元保存。
