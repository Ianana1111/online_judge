題目給的是多項式係數，但要的是導數在 x 的值。最高次係數 a 對應 ax^d，微分後就是 da·x^(d−1)。因此先把每個非恆定係數乘上它原本的次方，最後一個常數項直接忽略。

不用逐項算 x 的次方。把導數改寫成 (((d·a0)x+(d−1)·a1)x+...)，每讀一項就做 value=value*x+coefficient*degree。這是 Horner 法，既減少乘法，也避免另外保存所有次方。只有常數的多項式沒有迴圈，答案自然是 0。

第一行是 x，第二行的一整列係數決定次數，不能假設每個多項式的項數相同。C／C++ 用動態讀行與係數指標陣列，先數出項數，再做 Horner。Java 以分割後的長度求 degree，使用 BigInteger 乘加。

雖然輸入與最終答案都限制在 32 位元，中間的值仍可能超出；多項式可能先變得很大，後面再抵消。C／C++ 的帶符號十進位字串與 Java BigInteger 保存所有中間結果，不假設 64 位元足夠。d 次多項式只需 d 輪乘加；若中間最多 D 位、x 有 X 位，逐位乘法的主要成本 O(dDX)，另外包含係數乘次數的成本。
