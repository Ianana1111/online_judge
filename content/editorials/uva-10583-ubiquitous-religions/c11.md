每條配對只告訴我們兩人必須屬於同一信仰，經由傳遞性，沿著關係路徑連在一起的人都被迫同組。不同連通分量之間沒有相同限制；既然題目問「最多」種類，就可以讓每個分量各用一種不同信仰。因此問題等價於動態維護連通分量數。

把學生當節點、相同配對當無向邊，每個連通分量內的人被迫具有相同信仰。不同分量之間沒有任何必須相同的限制，為了最大化種類，可以各自指定不同信仰。因此答案正是連通分量數。

使用並查集。最初每個人自成一組，groups=n；每讀一對，找出兩人的根，若根不同就合併並將 groups 減一，根相同則不變。路徑壓縮與按大小合併讓查詢幾乎常數時間。不能每讀一條關係都減一，因為關係可能只是在同一連通分量內形成環。

C 與 Java 使用路徑壓縮和按集合大小合併；Python 也維持相同不變量。只有兩個根不同，宗教群數才減一。
