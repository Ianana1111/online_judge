The Fenwick tree is one-based. `add` advances by the lowest set bit, while `prefix` removes that bit to combine disjoint stored blocks; `range` subtracts `prefix(left-1)` to keep both endpoints.

In a `C` command, the variable named `right` is the new value. Boolean comparisons become zero or one, so new-minus-old yields the exact update delta. Both deltas are computed before replacing `value[left]`. Product queries append one character and print only after the case's commands finish.
