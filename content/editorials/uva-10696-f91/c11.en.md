`scanf("%ld", &n) == 1 && n != 0` ends the loop in two situations: no number can be read (end of file), or the required terminating 0 was read. The 0 never enters the loop body, so no extra line is printed for it.

Inside the loop there is a single comparison: when `n <= 100` the answer is always 91, otherwise it is `n - 10`. Both values are stored in `long`, which is far wider than the one-million limit.

C's `printf` is buffered, and when standard output goes to a file it is not flushed per line, so printing each line with `printf("f91(%ld) = %ld\n", ...)` is already fast. The format string fixes one space on each side of `=` and the parentheses exactly as the problem requires.
