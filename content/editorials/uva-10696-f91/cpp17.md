迴圈條件 `cin >> n && n != 0` 同時處理兩件事：讀到檔案結尾就停，讀到結尾的 0 也停，所以 0 永遠不會被輸出。n 用 `long long` 讀，雖然題目最大只有一百萬，但這樣不必擔心任何溢位問題。

答案直接用推導出的公式：`n <= 100 ? 91 : n - 10`。這裡的邊界是「小於等於 100」，100 本身屬於答案 91 的那一邊，101 則得到 91 = 101 − 10，兩段剛好接起來。

每一行先用 `to_string` 接到同一個字串 `out` 後面，最後才一次 `cout`。配合關閉同步的 `ios::sync_with_stdio(false)`，25 萬行輸出也只需要一次大量寫入，不會因為逐行 flush 而變慢。
