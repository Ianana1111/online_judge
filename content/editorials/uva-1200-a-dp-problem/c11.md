先別被方程式的字串嚇到，沒有括號也沒有乘除運算，所以每邊都只是幾個 x 項與常數項相加。讀完後一定能整理成 ax+b=cx+d；移項得到 (a−c)x=d−b。

parse 掃描一邊，先取正負號，再讀數字。如果接著遇到 x，就把這個數字加到係數；否則加到常數。x 沒有寫數字時係數為 1，但 0x 明確寫了數字，係數應為 0。因此要額外記錄 has_digits，不能只問數字是否為零。

若 a−c=0，d−b 也為零就是 IDENTITY，否則 IMPOSSIBLE。其餘情況只有一個分數解，但輸出要求向下取整，不是朝零截斷。例如 −3/2 要輸出 −2。C 先把分母調成正數，負分子除不盡時再減 1；Python 的 // 與 Java Math.floorDiv 已提供向下取整。

方程式最多 255 字元，每個輸入係數最多 1000，係數與常數加總很小，64 位元整數足夠。每個字元只讀一次，時間 O(L)，除輸入字串外只用固定狀態。
