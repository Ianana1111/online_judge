不一定要真的把每個人從圈裡刪掉。我們只關心最後那個人，不妨從「剩下一人時，他的位置是零」倒著往回追。每補回一輪，只需還原當時重新開始數數的位置偏移。這題比固定步長 Josephus 多出的工作，是把每個圈大小對到原本使用的那個質數，不能在倒推時又從二開始正著用。

逆向使用 Josephus 位置遞迴。只剩一人時，局部零基底位置為零。從剩餘 size−1 人還原到 size 人時，要加上當初這一輪使用的步長，再對 size 取模。原本有 n 人、還原到 size 人時，前面已淘汰 n−size 人，所以此輪使用零基底 primes[n−size]。

因此 size 從二增加到 n，更新 survivor=(survivor+primes[n−size])%size；最後加一轉回題目編號。最大的 n 只淘汰 3500 人，先產生前 3500 個質數即可，無需模擬或保存圓圈。

先列出所需質數，再從小規模往回推倖存者的零起點位置，最後轉成題目的 1 起點編號。
