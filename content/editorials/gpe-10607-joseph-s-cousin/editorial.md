## 題意與限制

圓圈中有一至 3501 人，編號一至 n。第一輪數第二人淘汰，第二輪數第三人，之後依序使用五、七、十一等質數作步長，每次從被淘汰者的下一位重新數一。求最後生存者編號，輸入零結束。步長不是固定常數，也不是每個較小子問題重新從質數二開始。

## 解題思路

不一定要真的把每個人從圈裡刪掉。我們只關心最後那個人，不妨從「剩下一人時，他的位置是零」倒著往回追。每補回一輪，只需還原當時重新開始數數的位置偏移。這題比固定步長 Josephus 多出的工作，是把每個圈大小對到原本使用的那個質數，不能在倒推時又從二開始正著用。

逆向使用 Josephus 位置遞迴。只剩一人時，局部零基底位置為零。從剩餘 size−1 人還原到 size 人時，要加上當初這一輪使用的步長，再對 size 取模。原本有 n 人、還原到 size 人時，前面已淘汰 n−size 人，所以此輪使用零基底 primes[n−size]。

因此 size 從二增加到 n，更新 survivor=(survivor+primes[n−size])%size；最後加一轉回題目編號。最大的 n 只淘汰 3500 人，先產生前 3500 個質數即可，無需模擬或保存圓圈。

## 範例推演

n=6 需要依序使用二、三、五、七、十一淘汰。逆向從 survivor=0 開始，size 二用十一得一，size 三用七得二，size 四用五得三，size 五用三得一，size 六用二得三；加一後生存者為四，符合範例。n=1 不淘汰任何人，迴圈不進入，直接輸出一。

## 正確性

某輪有 size 人，以零基底數第 p 人會淘汰位置 (p−1)%size，下一輪從位置 p%size 開始重新編為零。因而若下一輪生存者在重新編號中的位置為 j，在本輪位置就是 (j+p)%size。逆向從單人生存者開始套用此映射，每次所用質數由原淘汰輪次 n−size 決定，不會把步長次序倒錯。最後還原到原始 n 人座標，再轉一基底即得到真正生存者。

## 複雜度

先產生固定前 3500 個質數，預處理成本很小。每筆 O(n) 時間，除共用質數表外 O(1) 空間；n≤3501。與逐次刪除陣列元素相比，不需要 O(n²) 的移動成本。

## 常見錯誤

- 套固定步長 Josephus 公式。
- size 遞增時也從第一個質數正序取，錯配淘汰輪次。
- 還原時加 p−1，漏掉下一輪從下一人開始的位移。
- 最後忘記把零基底加一。
- n=1 仍存取不存在的淘汰輪次。
