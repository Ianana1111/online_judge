The vector's entries for 0, 1, and 2 begin at zero. The loop starts with largest side 3 and adds only triangles introduced by that side. Placing `1LL` before the factors makes the square 64-bit, while integer division by four implements the floor.

Precomputation is independent of query order and handles repeats directly. The input loop stops for any value below 3, as required, and indexes `triangles[n]` because rod length `n` is included.
