# 官方快報｜Python 3.15 進入最後 RC：新版本來了，刷題要跟著換嗎？

Python 3.15 距離正式版又近一步。新功能很吸引人，但準備考試與維護專案時，先確認「程式最後會在哪裡執行」，往往比搶先更新更有用。

*judge. 官方快報 · 2026/09/17｜消息日期：2026/09/01*

## 新聞現場

Python 核心團隊於 9 月 1 日發布 **3.15.0rc2**，稱其為最後一個預定的候選版本，正式版當時排定於 **10 月 1 日**推出。這仍是預覽版；官方呼籲套件維護者測試相容性，也提醒不建議用於正式營運環境。3.15 系列的變更包含明確的延遲匯入與預設 UTF-8 編碼。[查看 Python 官方公告](https://blog.python.org/2026/09/python-3150-rc2/)

## judge. 觀點：相容性也是解題能力

同一份程式，在自己的電腦能跑，不代表比賽提供的版本也支援所有語法。練習時，建議把「語言版本、輸入格式、允許的套件」一起列入解題筆記。

如果想嘗試新版，可以另外建立測試環境，拿幾份已經寫過的字串處理、排序與資料讀取程式做比較。先確認輸出完全一致，再看啟動時間或效能。遇到差異時，把問題縮成最小範例，通常比一次修改整份專案更容易找到原因。
