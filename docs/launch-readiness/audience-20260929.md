# Anonymous audience and coarse Taiwan geography

Entry point: `/admin/audience` (後台 → 訪客分析). Both the page and the API require an administrator. The API sends `private, no-store`; aggregation is cached server-side for 30 seconds.

## Definitions

- Visitors are distinct browser identifiers, not proven people. An HttpOnly, SameSite=Lax first-party random cookie lasts up to 180 days since last use. Only its keyed hash is stored with events. No fingerprinting is used.
- An engaged view requires at least 10 seconds of visible-page time and a trusted pointer, keyboard, touch or scroll event. The server additionally checks elapsed time since the original view. Known bots/spam, `navigator.webdriver`, administrators and admin routes are excluded. These signals are estimates and can be spoofed.
- A page's engagement update uses the same event ID. A unique scoped event key prevents retries from increasing pageviews. The update cannot create a view or alter another visitor's view.
- A session preserves the original referring origin across client-side navigation and reloads; a new session is created after 30 minutes without a recorded page entry. Referrer paths, query strings, input contents and submitted code are not collected.
- “Direct / unknown” includes bookmarks and typed URLs as well as browsers/apps that omit a referrer. External referrals can be real humans too. Source totals overlap when a browser uses several entry sources.
- Anonymous means no login was observed for that browser in the selected time/source subset. It does not prove that the person never registered. The most privileged state observed in that subset classifies the browser, so a guest later seen signed in is not still counted as anonymous.
- Free means no valid Pro entitlement was observed. No automatic subscription means no ACTIVE subscription was observed for a signed-in browser; cancelled subscribers with remaining entitlement can appear in this category. Student/manual Pro and paid recurring subscription are deliberately separate concepts.
- Dates/hours interpret Prisma's UTC `TIMESTAMP(3)` correctly before converting to Asia/Taipei. This also fixes the older traffic dashboard's reversed offset.

## Geography and privacy

`GET /api/analytics/context` reads Vercel's country and first-level region headers, not arbitrary client JSON or raw forwarding headers. It never reads/stores raw IP or GPS coordinates. Geography is accepted only on Vercel; other hosting environments return unknown.

The web service signs a one-hour context using `ANALYTICS_CONTEXT_SECRET`. The API verifies the signature, expiry and claim shape before accepting the browser ID/country/region. Cookies and authentication still travel directly to the existing API; client-reported membership is never trusted. Set the SAME random secret (32+ characters, preferably 32 random bytes encoded as hex) on Vercel web and Railway API. Do not expose it as a `NEXT_PUBLIC_` variable or reuse an authentication key. Without the secret, legacy pageview counting remains available, while new visitor/location statistics are explicitly unavailable.

Taiwan distribution assigns each engaged browser its latest known country/region within the chosen subset. Unknown region codes remain “台灣・縣市未知”; missing countries remain unknown. VPN/mobile/campus/company networks may locate the network exit instead of the reader. No district, street address or individual location lookup is exposed.

DNT and GPC disable this self-hosted tracker. Analytics keeps the existing 400-day retention. `/privacy` documents the new fields and first-party cookie. Previous pageviews have null identity/geography and are excluded from unique-visitor reporting; there is no invented historical backfill.

Vercel source: https://vercel.com/docs/headers/request-headers#x-vercel-ip-country-region
