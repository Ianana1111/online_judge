## 重現 Set Partition 的容量證據

這是合法輸入的計數證明，不需要真的印出數百萬行：

```python
values = list(range(1, 30)) + [31]
total = sum(values)
count = [0] * (total + 1)
count[0] = 1
for value in values:
    for target in range(total, value - 1, -1):
        count[target] += count[target - value]
assert count[total // 2] == 8_650_610
assert count[total // 2] * 3 > 8 * 1024 * 1024
```

對每個元素倒序更新確保只選一次，`count[s]` 計算總和為 s 的子集合數。集合元素皆不同、正值、不超過 10¹²，元素數恰為 30，符合目前題面。
